# OhMyShokz

개인용 macOS 앱 MVP입니다.

- YouTube 링크 입력
- 앱에서 영상 미리보기
- 링크의 `t/start/end` 시간을 시작/종료 입력에 자동 반영
- 플레이어 현재 시각으로 시작/종료 시간 자동 입력
- 시작/종료 시간 지정 후 MP3 생성
- 영상 저장 리스트(큐) 저장/편집/일괄 변환
- 저장 폴더 지정
- `/Volumes` 기준 Shokz 후보 자동 탐지
- 다운로드 파일 목록 + 전송 상태 표시
- 파일별 원클릭 기기 복사

## Local Run

필수:

- Node.js 20+

```bash
npm install
npm start
```

도구 설치:

- `ffmpeg`는 앱에 포함됩니다.
- `yt-dlp`는 앱에서 `도구 자동 설치` 버튼으로 설치됩니다.

## MP3 구간 추출

- 시간 형식: `HH:MM:SS` 또는 `MM:SS`
- 시작/종료 둘 다 입력하면 해당 구간만 MP3로 생성
- 둘 다 비우면 전체 길이 기준으로 MP3 생성
- `현재 시각을 시작으로`, `현재 시각을 종료로` 버튼으로 플레이어 위치를 바로 입력 가능
- 임베드가 막힌 영상은 fallback 시간 바(range)에서 시작/종료를 지정 가능

## 영상 저장 리스트

- `리스트에 저장` 버튼으로 링크를 누적 저장합니다.
- 항목별로 `파일명`, `시작`, `종료`를 수정할 수 있습니다.
- `리스트 일괄 변환`으로 저장된 항목들을 순차 MP3 변환합니다.
- 리스트는 로컬 저장소에 유지되어 앱 재시작 후에도 남아 있습니다.

## 기기 전송

- 앱이 `/Volumes`의 디스크 이름에서 `shokz/swim/openswim` 키워드로 자동 후보를 보여줍니다.
- 필요하면 `직접 선택`으로 기기 폴더를 수동 지정할 수 있습니다.
- 파일 목록의 `기기로 복사` 버튼으로 선택한 기기 폴더에 MP3를 복사합니다.

## GitHub Actions (DMG)

워크플로 파일: `.github/workflows/build-dmg.yml`

- 수동 실행: `Actions > Build DMG > Run workflow`
- 태그 푸시: `git tag v0.1.0 && git push origin v0.1.0`

결과:

- Action artifacts에 `OhMyShokz-dmg` 업로드
- 태그 빌드면 Release assets에도 `.dmg` 첨부

## macOS 최초 실행

이 앱은 Apple Developer ID 공증을 받지 않은 개인 배포 앱입니다. 처음 실행할 때 macOS가 앱을 차단하면 `xattr` 명령 대신 다음 절차로 한 번만 허용하세요.

1. 앱을 한 번 실행해 macOS 경고를 확인합니다.
2. `시스템 설정 > 개인정보 보호 및 보안`을 엽니다.
3. 보안 영역에서 OhMyShokz의 `그래도 열기`를 누릅니다.
4. 확인 창에서 다시 `열기`를 선택합니다.

이후에는 Finder에서 평소처럼 실행할 수 있습니다. 회사에서 관리하는 Mac은 보안 정책에 따라 `그래도 열기`가 허용되지 않을 수 있습니다.

## Notes

- 이 앱은 YouTube 콘텐츠를 자동 저장하므로, 본인 권리/라이선스가 있는 콘텐츠만 사용하세요.
- Shokz 기기마다 파일 복사 방식이 다를 수 있습니다. OpenSwim 계열은 USB 저장소 복사 방식이 일반적입니다.
